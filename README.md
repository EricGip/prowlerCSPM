# prowlerCSPM

Our Goal:
In this project, we will set up AWS resources that are intentionally vulnerable with Terraform, scan them with Prowler, an open source security assessment tool, and remediate the vulnerabilities Prowler detected through Terraform also.

What i’ve learned
Fortunately I learned most of these issues while studying for the AWS Associate — Solutions Architect exam, but I haven’t been able to put the knowledge into practice. By setting up intentionally vulnerable resources in an environment, I was able to learn how detrimental missing one line of code in a terraform can be.

I was able to practice securing IAM policies, S3 access rules, SSH rules, enforcing encryption, and services that maintain security.
